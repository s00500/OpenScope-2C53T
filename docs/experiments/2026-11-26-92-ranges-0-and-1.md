# EXP-92: ranges 0 and 1 have gains: 0.40 and 0.80 mV per count

- **Date:** 2026-11-26
- **Unit:** my unit
- **Build:** `guest-coldtrace` `Nov 26 2026 23:42:09` (`siggen dccode`); the
  table change on `23:53:37`
- **Setup:** GEN into CH2 by a BNC cable, then into CH1; DC coupling during
  the sweeps; offset references at their boot codes (CH1 DAC1 2048, CH2
  TMR13 2114)
- **Source scale:** EXP-80, GEN = 0.7937 mV per DAC code
- **Status:** CONFIRMED

## 1. Problem

Ranges 0 and 1 were the last without a gain. EXP-89 showed they do not rail
with a quiet input and that they are more sensitive than range 2, but the
generator's DC levels move in 98 mV steps (`amp` in 0.1 V), more than a
hundred counts there. Does a finer source exist? The DAC behind GEN is 12-bit
at 0.79 mV per code: only the command was coarse.

## 2. Hypothesis

With GEN at raw DAC codes, ranges 0 and 1 are linear, about 0.4 and
0.8 mV per count (the ladder's x2 / x2.5 pattern continued down), equal on
both channels within a few percent; and the fit's intercept, against the
EXP-89 zero, puts GEN's own 0 V at the same +7..+10 mV as the other ranges.
Falsifier: nonlinear residuals, channels apart, or an intercept that needs
a different zero.

## 3. Procedure

- `siggen dccode N` (`signal_gen.c`): every sample of the cycle at DAC code
  N, waveform DC, until the next waveform/amplitude/duty change.
- `captures/exp92/codesweep.py ch2 3 2 1 0`, then `ch1`: per range, codes 0
  and 40 for the slope, then 8 levels from code 0 to about 200 counts; 3
  records per level; fit counts against code x 0.7937 mV; intercept less the
  EXP-89 zero at the offset code in force = GEN's 0 V.

**Preconditions verified by readback:** `siggen` shows `dccode 1881 (raw DC,
~1493 mV)` and `siggen dump` the cycle at 1881; offset codes by `fpga scope
zero` (2048 / 2114); settings restored after each run (`settings diff: {}`).

- Into `scope_cal`: ranges 0-2 from this run, MEASURED (range 2 was

On my unit with the table in: `fpga scope cal` lists 13 / 26 / 64 mV per
division for ranges 0-2; CH1 range 0 at code 30 reads 132.69 counts =
33.8 mV (33.7 expected); the autoset on GEN's smallest sine (CH1 alone)
picks range 1 as predicted (98 mVpp, 3.8 div at 26 mV/div), Freq 994.8 Hz,
Vrms 34 mV. Screenshots (`captures/exp92/`, weak evidence).

## 6. Blind spots

- One unit, one session, one temperature; the zero's ±0.3 counts is
  ±0.12 mV on range 0, but its drift is unmeasured.
- Only 0..~70 mV (range 0) and 0..~95 mV (range 1) above 0 V were swept:
  the generator does not go negative, and 0 V sits near the converter's
  bottom, so the negative part of these ranges (about -20 / -40 mV) is
  untested.
- With both channels on, CH1's 0 V is mid-half: only 1.65 divisions above
  it, 21 mV on range 0. A level above that is off the screen (it flattens on
  the edge, as the first screenshot shows); Position or the autoset moves it.

## 7. Conclusion

- **Established:** every range now has a gain on both channels; ranges 0
  and 1 are linear (residuals under 0.7 counts) and agree between channels
  within 1.3 %; the EXP-89 zero holds for them (GEN's 0 V the same on all
  ranges). No better source was needed: the generator's DAC was always fine
  enough, only its command was coarse.
- **Not established:** the negative half of ranges 0-1; drift.
